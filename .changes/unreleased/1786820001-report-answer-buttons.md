type: Changed
title: One button per question on the report
---

Blood and mood swings are now a pair of large buttons — the glyph over its name, lit in the app's red when it happened and dimmed when it did not — instead of a Yes/No pair each. A day is still filed by **Save**, so saving with neither button lit remains the explicit "I checked, nothing happened" it always was. [Learn more](feature:daily-report)
