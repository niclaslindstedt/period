type: Fixed
title: A fever reads as "Fever", not as 38.00
---

The temperature slider's top stop stores 38.00 °C because the document needs a number for "febrile", and the box used to show that back as if you had measured it. It now says **Fever** in both units, and a fever set on the slider is no longer cleared by tapping into the box and back out. [Learn more](feature:daily-report)
